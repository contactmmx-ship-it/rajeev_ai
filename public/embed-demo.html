Rajeev AI widget test

This page loads the shared Rajeev AI widget as the ebill2tally project, so you can check it before adding it to a real app.

Tap the round button at the bottom right, then Start talking.

To add Rajeev AI to any project, paste one line into that project's page:

<script src="https://YOUR-RAJEEV-AI-HOST/rajeev-widget.js" data-project="ebill2tally" defer></script>
